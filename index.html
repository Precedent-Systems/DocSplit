Smart Legal Document & Docket Slicer

DocSplit automatically inspects massive 1,000-page court records, appellate dockets, and exhibit packets, slicing them into cleanly titled individual document PDFs by bookmark TOC and legal header boundaries.

🚀 Get Started on GitHub Read CLI Documentation
📑

Docket Bookmark TOC Slicer

Reads internal PDF bookmarks to extract each motion, complaint, declaration, and order into separate files titled by filing date and name.

docsplit split court_record.pdf
⚡

Zero Size Limits (Local & Free)

No paywalls or 50-page file size caps. Slices 1,000+ page court volumes in under 5 seconds directly on your local machine.

1,000 pages -> 149 individual PDFs
🔍

Docket Inspector & Indexer

Inspects any court record PDF and outputs a structured JSON index table of all internal filing dates, page ranges, and document titles.

docsplit inspect court_record.pdf

DocSplit CLI Integration

# 1. Install DocSplit locally git clone https://github.com/Precedent-Systems/DocSplit.git cd DocSplit pip install -e . # 2. Slice a massive court record volume into individual document PDFs docsplit split "/path/to/23CV23393 Volume 1.pdf" # 3. Inspect document TOC structure without extracting docsplit inspect "/path/to/23CV23393 Volume 1.pdf"
